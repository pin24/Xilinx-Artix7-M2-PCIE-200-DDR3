# Троичный FP-ускоритель TFloat48 — блочная архитектура (итог работы)

## Цель
Перенос тяжёлых матричных операций (dot/GEMM для обучения и инференса нейросетей)
с CPU на FPGA Xilinx XC7A200T (M.2-плата), с интеграцией в кастомные слои PyTorch
через XDMA + DDR3.

## Формат TFloat48 (финальный)
- **48 бит = 6 байт**, разбиение на блоки по 4 трита (= 1 байт).
- M = 20 тритов (5 байт) — мантисса, нормализована [3^18, 3^19).
- E = 4 трита (1 байт) — экспонента, bias 40.
- value = M * 3^(e - 18), где e = E - 40.
- Точность мантиссы 3^-18 ≈ 5.2e-9 (в ~22 раза точнее float32 1.19e-7).
- Кодирование трита: +1->01, 0->00, -1->10, 11->ERR (2 бита).

## Блочная архитектура (ключ к успеху)
Разбиение на 4-тритные блоки (байты) радикально снизило LUT:
- **tbyte_add.sv**: сложение 4+4 трита + перенос → 4 трита + перенос. 17 LUT. 5000/5000 PASS.
- **tbyte_mul.sv**: умножение 4×4 трита → 8 тритов (поразрядное). 1190 LUT. 5000/5000 PASS.
- **tfmac.sv**: полный MAC (mul 25 тактов + add + нормализация). 5338 LUT. 800/800 PASS.
- **tfmul.sv**: умножитель с нормализацией. 6625 LUT (дорогой из-за val_abs/floor_div3).
- **tfmul_raw.sv**: умножитель БЕЗ нормализации (25 тактов, prod 40 тритов, e, neg) — ~2k LUT.
- **tfadd_raw.sv**: adder ненормализованных (выравнивание /3^k, сложение 42 тритов, нормализация со знакосохранением).
- **compute_dot_par_raw.sv**: параллельный dot, параметр NUM_MAC.

## Результаты синтеза (XC7A200T, jobs 19, DSP=0, BRAM=0)
| NUM_MAC | LUT | % | Решение |
|---------|-----|---|---------|
| 16 | 111 306 | 82.7% | ✓ (старая версия с полной норм.) |
| 32 | 60 511 | 45% | ✓ (raw-версия) |
| **64** | **114 865** | **85.3%** | ✓ **ФИНАЛ (raw-версия)** |

Симуляция против Python (arith48): PASS для 16/32/64.
Последовательный вариант (1 MAC): 7 802 LUT (5.8%), dot N за ~400 тактов.

## Критичные баги, исправленные в raw-версии
1. Беззнаковые экспоненты в tfadd_raw → сравнение e_sum < -40 всегда истинно, зануляло результат.
2. Потеря знака при нормализации (|sum| вместо знакосохраняющего).
3. Unsigned распаковка экспоненты на уровнях дерева + счётчики 6→8 бит (для 64).

## Верификация
- Python-эталон: `ternary_sw/block/tfloat48.py`, `arith48.py` (формат 20M+4E).
- verify-скрипты: `rtl/block/verify_*.py` (запуск: `C:\Python39\python.exe verify_XXX.py`).
- Raw-модель RTL в verify (`_rhu_next`, `_norm_raw_rtl`) — отличается от arith48.mul (который нормализует продукты).

## PyTorch-интеграция (каркас готов)
- `pytorch_layer/fpga_backend.py` — интерфейс (CPU-эмуляция сейчас, FPGA через XDMA позже).
- `pytorch_layer/ternary_dot_layer.py` — кастомный слой PyTorch.
- Точность на CPU-эмуляции: разница с torch.dot ≈ 1.4e-6 (уровень float32).
- PyTorch 2.8 (CPU) установлен: `C:\Python39\python.exe`.
