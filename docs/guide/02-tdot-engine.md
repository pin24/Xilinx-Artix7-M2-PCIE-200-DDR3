# 02. Движок dot (ядро tdot)

## Что вычисляет
Один вызов ядра считает скалярное произведение двух векторов длины `n`:
```
dot = Σ_{i=0}^{n-1} data[i] · weights[i]
```
Числа — **TFloat48**: знак + мантисса (40 «тритов», т.е. цифры в {-1,0,1}) + экспонента
(8 бит, множитель 3^x). Такая система даёт очень широкий динамический диапазон и
почти нулевую потерю при суммировании (аккумулятор без переполнения на практичных длинах).

## Параметры конфигурации (compile-time)
- **NUM_MAC** — число параллельных умножителей (ширина размножения). На плате 32.
- **ADDERS** — число параллельных аддеров дерева редукции. На плате 8.
- **MAX_PASSES** — потолок проходов для «длинного dot» (>NUM_MAC пар), в RTL = 32.

Файл ядра: `rtl/block/compute_dot_par_raw.sv`.

## Точность и редукция
- Умножение: `tfmul_raw` (точно, затем нормализация).
- Суммирование: дерево из тайэров (`add`), ADDER параллельно; на конце — единый результат.
- Длинный dot (`n > NUM_MAC`): авто-разбиение на чанки по NUM_MAC, накопление аккумулятором
  (`tfadd48`), до `MAX_N_TOTAL` пар за один вызов.

## Потолок ширины одного dot
```
MAX_N_TOTAL = MAX_PASSES × NUM_MAC
```
- на 32/8: 32 × 32 = **1024**.
- Если `n > MAX_N_TOTAL` — ядро насыщает (`sat_q`) и результат неверен (обрезается до 1024).

## Блоки и юниты
- `rtl/block/`: `tbyte_mul`, `tbyte_add`, `tfmul_raw`, `tfadd_raw`, `compute_dot_par_raw`,
  `tfadd48` (длинный аккумулятор).
- `rtl/integration/tdot_axi4.sv` — полный AXI4-мастер вокруг ядра: планировщик, чтение
  data/weights из DDR, запись результата, device_prog-режим, кольцо, OBS-наблюдаемость.

## Регистры низкого уровня (tdot, AXI-Lite, 0x40023000+off)
| off | Регистр | Смысл |
|---|---|---|
| 0x00 | CTRL | bit0 GO (легаси одиночная задача) |
| 0x04 | STATUS | bit0 BUSY, bit1 DONE |
| 0x08 | N_IN | число пар для легаси-задачи |
| 0x14..0x28 | DATA/WEIGHTS/RESULT addr | адреса в DDR |
| 0x64 | CORE_PARAMS | [7:0]=NUM_MAC, [15:8]=ADDERS |
| 0x68 | MAGIC | 0x54444F54 ('TDOT') |
| 0x6C..0xAC | OBS_* | счётчики наблюдаемости (если доступны) |

## Как использовать напрямую (легаси)
```
# пример: data@0x1000, w@0x2000, result@0x3000, n=4
# (через pytorch_layer / xdma_driver; см. 04-host-software.md)
runner.set_N(N); runner.set_data_addr(...); runner.go(); runner.wait_done()
```
Обычно же используют **device_prog** (батч/программа слоёв) — см. `03-device-prog.md`.
