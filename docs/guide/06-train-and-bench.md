# 06. Обучение на FPGA, бенч FPGA vs CPU, пропускная способность

## Как работает обучение на FPGA
Host-FPGA ко-дизайн: **умножение-накопление (GEMM/dot) — на движке**, остальное — на хосте.

Цикл эпохи (`scripts/train_dprog_batch_mlp.py`):
1. Host пишет батч `X` и веса `W1,W2` в DDR (h2c).
2. **FPGA** (device_prog n_batch) читает их и считает все dot скрытого и выходного слоёв:
   `H = X·W1ᵀ` (B×H), `OUT = A·W2ᵀ` (B×O); пишет результаты в DDR.
3. Host читает H/OUT (c2h), делает sigmoid, ошибку, обновляет веса на numpy, пишет их обратно.
4. Повтор для каждого батча.

## Обучение (команды)
```
# быстрое (256 сэмплов, 3 эпохи, дефолтный LR=0.5): может расходиться на больших батчах
python scripts/train_dprog_batch_mlp.py --epochs 3 --batch 32 --samples 256 --lr 0.5 --seed 0
# устойчивое (1000 сэмплов, 8 эпох, LR=0.1)
python scripts/train_dprog_batch_mlp.py --epochs 8 --batch 32 --samples 1000 --lr 0.1 --seed 0
```
Пример сходимости: MSE 0.85 → 0.31 за 8 эпох (1000 сэмплов). Взрыв MSE на больших
батчах/поздних эпохах = дивергенция градиентного спуска (снизить LR), не плата.

## Сравнение FPGA vs CPU (`scripts/bench_fpga_vs_cpu.py`)
```
python scripts/bench_fpga_vs_cpu.py --hidden 16 --mem 2M --epochs 3 --batch 32 --samples 256 --lr 0.1 --wide 1024
```
- Часть 1: обучение того же MLP на FPGA и CPU, время/эпоху + ratio.
- Часть 2: широкий dot (N_IN) throughput.
- `--hidden H` — ширина скрытого слоя; `--mem` (128K/1M/2M/…) — рабочая область DDR,
  потолок 85% DDR с урезанием+сообщением; буферы раскладываются последовательно.

Типичный результат (32/8):
| H | CPU ms/эп | FPGA ms/эп | ratio CPU/FPGA |
|---|---|---|---|
| 16 | 0.14–0.39 | ~980 | ~0.0002× |
| 64 | ~0.14 | ~485 | ~0.0003× |
| 512 | ~0.84 | ~503 | ~0.0017× |
| 1024 | ~0.29 | ~518 | ~0.0006× |

**Вывод:** для малых GEMM CPU быстрее на порядки — из-за фиксированной накладной на
один запуск device_prog (DMA+GO+mailbox ~0.3–1 с/эпоху). FPGA выгоден при амортизации
overhead на многих dot (батч). Ценность акселератора — offload/детерминизм.

## Пропускная способность каналов (MB/s)
| Размер | h2c | c2h | round-trip |
|---|---|---|---|
| 64КБ | 11.1 | 4.2 | 2.1 |
| 256КБ | 17.4 | 16.9 | 17.0 |
| 1МБ | 71.9 | 65.3 | 34.0 |
| 4МБ | 71.7 | 65.8 | 38.9 |
| 16МБ | 67.8 | 66.7 | 36.2 |

Устойчивый предел ~70 MB/s.

## Потолок скрытого слоя H
- Работает до **H=1024** (MAX_N_TOTAL = 32×32). Выше (H=2048) движок sat/clamp → неверно.
- `--mem` управляет только раскладкой DDR-буферов: `B×H×8 ≤ mem`, `--mem ≤ 85% DDR`.
