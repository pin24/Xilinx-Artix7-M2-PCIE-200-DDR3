# RISK_REGISTER — риски и открытые вопросы

> Формат: ID · риск · влияние · вероятность · владелец · способ снятия/закрытия. Обновлено 2026-09-11.

## Открытые риски

| ID | Риск | Влияние | Вероятн. | Владелец | Критерий закрытия |
|---|---|---|---|---|---|
| **R-01** | **Битстрим на плате не соответствует текущим скриптам** (измерено BAR0=1 МБ против `pf0_bar0_size=128` в `build_dfx.tcl`); записи в AXI-Lite не залипают, XADC недостижим | 🔴 Высокое: функциональные тесты не проходят, железо ведёт себя не по документации | Реализовался (подтверждено измерением) | FPGA-инженер/пользователь | Инструкция: `driver/R-01_BUILD_AND_FLASH.md`. Критерий: пересборка `make build` в Vivado 2025.2 → прошивка флеша (`scripts/flash_program.tcl`) → power-cycle → измерение BAR: **BAR0=131072 КБ (128 МБ)**; GPIO/TDOT/XADC/PROTO/ICAP — PASS |
| **R-02** | Модуль DDR3/MIG не проверен на калибровку/работоспособность в текущей сборке | 🟠 Среднее: DMA-путь к DDR3 не подтверждён | Средняя | FPGA-инженер | `init_calib_complete=1` (GPIO2 bit1) + успешный `xdma_driver.py --selftest` (паттерн h2c/c2h) |
| **R-03** | Тесты `icap`/`proto` не прогонялись (риск аппаратных сбоев при неизвестном битстриме) | 🟠 Среднее: протокол ICAP и long-dot на железе не подтверждены | Средняя | Пользователь | После перепрошивки прогнать `test_xdma.exe icap` и `proto` по одному; отсутствие AER/BSOD, корректный readback регистров |
| **R-04** | XADC недоступен (BUG-031: XADC занят MIG), температурный мониторинг отсутствует | 🟡 Низкое/среднее: `monitor_temp.py` не даёт реальной температуры | Реализовался | Пользователь | Реализовать чтение температуры через MIG DRP (TODO из ADDRESS_MAP §7) или принять ограничение |
| **R-05** | Windows-путь Python-обвязки зависит от `xdma_rw.exe` (не входит в репозиторий) | 🟡 Низкое: хост-API на Windows не заработает без утилиты | Средняя | Пользователь | Положить `xdma_rw.exe` в PATH или собрать из `xdma_driver_win_src_2017/exe`; проверить `XdmaWindows.read/write` |
| **R-06** | Полная сборка FPGA (synth/impl) не выполнялась в этой сессии | 🟠 Среднее: нет подтверждения, что текущие скрипты собираются после правок | — | Пользователь/FPGA-инженер | `make build NUM_MAC=4` (или 8) с FATAL-гейтом тайминга → успешный битстрим |
| **R-07** | Драйвер подписан тестовым сертификатом (testsigning) | 🟡 Низкое: непригоден для production/других машин без тест-режима | — | Пользователь | Для продакшна — подпись через Microsoft Attestation/EV-сертификат |
| **R-08** | Историческая нумерация `docs/ERROR_HISTORY.md` (до BUG-052) и новые записи в `driver/ERROR-FIX-LOG.md` живут раздельно | 🟡 Низкое: расхождение журналов | — | Пользователь | При следующем изменении кода добавить запись и в `docs/ERROR_HISTORY.md` (BUG-053+) со ссылкой на E-xx |
