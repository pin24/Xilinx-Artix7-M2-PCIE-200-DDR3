2. BSOD-1/2 — почему падало на 0x1067

Дизассемблирование показало: падение — вызов WdfDriverCreate в DriverEntry. Индекс таблицы: 0x3A0 / 8 = 116 = WdfDriverCreateTableIndex (wdffuncenum.h, KMDF 1.15). Таблица WdfFunctions заполняется заглушкой FxDriverEntry (wdfdriverentry.lib) через WdfVersionBind (импорт из WDFLDR.SYS). В собранном образе импортов из WDFLDR не было вовсе, т.к. линковка шла с /entry:DriverEntry.

; XDMA+0x1000 (DriverEntry, старая сборка)
mov  rcx, [XDMA+0x3088]   ; WdfDriverGlobals = NULL
mov  rax, [XDMA+0x3090]   ; WdfFunctions     = NULL
call qword ptr [rax+3A0h] ; -> чтение [0x3A0] -> c0000005
Исправление (FIX-8): в build.cmd точка входа — /entry:FxDriverEntry (как в WDK: WindowsDriver.KernelMode.KMDF.props). После пересборки в образе есть импорты WDFLDR.SYS: WdfVersionBind/Unbind/BindClass/UnbindClass, точка входа 0x1988, драйвер загружается без падения.

3. BSOD-3 — фатальная ошибка PCIe (аппаратный уровень)

Стек дампа не содержит кадров XDMA.sys — bugcheck поднял корневой порт PCIe по сигналу AER от платы. Источник — обращение к BAR2. Измерения через собственный IOCTL драйвера:

BARФизадресРазмер (факт)Что ожидалось по документации
BAR0 (AXI-Lite)0xA81000000x100000 — 1 МБ128 МБ (pf0_bar0_size=128 в build_dfx.tcl)
второй BAR0xA80F00000x10000 — 64 КБв DFX-сборке это таблица MSI-X (DDR3 — только через DMA, ADDRESS_MAP §1.2)

Драйвер без проверки принимал второй BAR как окно DDR3; тест DDR3 писал в него → неподдерживаемая транзакция → Completer Abort → AER → bugcheck 0x124.

Исправление: FIX-11 (driver.c) — второй BAR принимается только при размере ≥ 16 МБ, иначе не маппится и DDR3-запросы возвращают STATUS_DEVICE_NOT_CONNECTED без обращения к железу (+ DbgPrint-диагностика). FIX-12 (test_xdma.c) — предполётный опрос BAR; тесты DDR3 и XADC печатают SKIP, если область недоступна.
Важно (R-01): измеренный BAR0 = 1 МБ противоречит скриптам (128 МБ) — на плате загружен устаревший битстрим. Это объясняет и то, что записи GPIO_TRI/TDOT_N_IN не залипают. Требуется пересборка в Vivado 2025.2 и перепрошивка.
