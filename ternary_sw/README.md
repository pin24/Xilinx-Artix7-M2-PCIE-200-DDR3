# Ternary FP Accelerator - программный эталон (TFloat40)

Эталонная реализация троичной симметричной системы счисления с плавающей
точкой для аппаратного ускорителя на Xilinx XC7A200T (M.2 плата).

## Формат TFloat40

* **20 тритов = 40 бит** (2 бита на трит)
* Мантисса: 15 тритов (старшие)
* Экспонента: 5 тритов (bias = 60, balanced ternary)
* Кодирование трита: `+1 -> 01, 0 -> 00, -1 -> 10, ERR -> 11`
* Значение: `value = M * 3^(E - 60 - 13)`, где M - целая мантисса
  (15 тритов), нормализованная к [3^13, 3^14)

Точность мантиссы: 3^-15 ~= 6.9e-8 (близко к float32 = 1.2e-7).

## Структура

```
ternary_sw/
├── ternary/
│   ├── __init__.py
│   ├── trits.py      # тритовая арифметика (коды, сложение, упаковка)
│   ├── tfloat40.py   # формат TFloat40 (конвертеры float32 <-> TFloat)
│   └── arith.py      # операции + - * / (эталон для RTL)
├── tests/
│   └── test_tfloat40.py   # pytest тесты
├── verify_cpu.py     # сверка с float32 (точность, ULP)
└── gen_reference.py  # генерация эталонных векторов для FPGA
```

## Внутренняя конвенция (важно для RTL)

* Мантисса хранится как **целое** M (15 тритов), нормализована к [3^13, 3^14)
* `value = M * 3^(e-13)`, где e = E - 60
* Умножение: `M = Ma*Mb / 3^13` (в RTL - P/N-разложение + DSP48E1)
* Деление: поразрядное, полная точность (в RTL - restoring division)
* Ошибочный трит (11) - аналог NaN, флаг ошибки
